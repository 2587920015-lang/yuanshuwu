# 元书屋 - Web 版

小说书店网页应用，无需服务器、无需注册第三方服务，浏览器打开即用。

## 功能

- 👤 **账号系统** — 注册/登录，每人独立书架
- 💰 **扫码支付 + 人工审核** — 买家扫码→提交→管理员确认→书籍入架
- 🔄 **导入/导出同步** — 管理面板一键导出/导入 JSON，跨设备同步数据
- 📖 **阅读器** — 目录导航、字号/夜间模式、进度记忆

## 🚀 使用方式

1. 双击 `index.html` 浏览器打开
2. 部署到任意静态托管（GitHub Pages / Netlify / Vercel / 服务器）获得公网网址
3. 买家打开网址注册购买，管理员登录审核

> 💡 最简单部署：打开 [app.netlify.com](https://app.netlify.com) → 拖入整个文件夹 → 获得网址

## 🔐 管理员审核流程

### 同设备（默认）
```
买家登录 → 购买 → 扫码支付 → 提交
                              ↓
管理员登录 → ⚙️管理面板 → 看到订单 → ✓确认
                              ↓
                      买家获得书籍 ✅
```

### 跨设备（导入导出）
```
买家手机 → 购买 → 订单存在手机浏览器中
                    ↓ 管理员导出
管理员电脑 → 打开网页 → ⚙️ → 📤导出数据
                    ↓ 发送JSON文件到买家手机
买家手机 → ⚙️ → 📥导入数据 → 订单同步到管理员端
                    ↓ 管理员确认
           → 买家获得书籍 ✅
```

> 实际使用中，买家付完款通知管理员，管理员在自己的设备上审核即可（订单都在同一浏览器中）。

## 📦 文件结构

```
bookstore-web/
├── index.html          # 主页面（打开即用）
├── css/style.css       # 样式
├── js/
│   ├── store.js        # 数据管理（localStorage）
│   └── app.js          # 应用逻辑
├── data/chapters/      # 321章小说数据（7个文件懒加载）
├── images/
│   └── payment-qrcode.jpg  # 收款码
└── README.md
```

## 🔧 自定义

| 内容 | 文件 | 方式 |
|------|------|------|
| 收款码 | `images/payment-qrcode.jpg` | 替换图片 |
| 管理员 | 默认 `yuan` / `xiaoyuan123` | 登录后在代码中修改 |
| 书籍价格 | `data/chapters/book-data.js` | 修改 `price` 字段 |
| 书店名称 | `index.html` | 搜索替换「元书屋」 |
