# 元书屋 - Gitee Pages 部署指南

Gitee（码云）国内服务器，100% 可访问，永久免费。

---

## 第1步：注册 Gitee

1. 打开 [gitee.com](https://gitee.com)
2. 点右上角 **「注册」**
3. 输入手机号/邮箱 → 设置密码 → 注册
4. 注册后登录

---

## 第2步：创建仓库

1. 登录后，点右上角 **「+」** → **「新建仓库」**

2. 填写信息：
   - **仓库名称**：`yuanshuwu`（英文，随意起）
   - **仓库介绍**：元书屋
   - **是否开源**：选 **「私有」**（你卖书的，选私有）
   - 其他保持默认

3. 点 **「创建」**

---

## 第3步：上传文件

创建完仓库后会跳转到仓库页面。

### 方法A：网页上传（推荐，不用装任何东西）

1. 在仓库页面点 **「上传文件」** 按钮
2. 打开你电脑上的 `d:\VPN\Claude\bookstore-web` 文件夹
3. **全选**里面的所有文件和文件夹，拖到网页上传区域
4. 提交信息随便填，比如「初始化」
5. 点 **「提交」**

### 方法B：用 Git 命令（如果你装了 Git）

```bash
cd d:\VPN\Claude\bookstore-web
git init
git add .
git commit -m "init"
git remote add origin https://gitee.com/你的用户名/yuanshuwu.git
git push -u origin master
```

---

## 第4步：开启 Gitee Pages

1. 上传完成后，在仓库顶部菜单点 **「服务」** → **「Gitee Pages」**

2. 页面中：
   - **部署目录**：保持默认（留空或填 `/`）
   - **部署分支**：选 `master`
   - 点 **「启动」**

3. 等待几秒钟 → 出现一个网址：

   ```
   https://你的用户名.gitee.io/yuanshuwu
   ```

4. 点这个网址 → 浏览器打开 → 看到登录页面 → ✅ 部署成功！

5. **点「更新」按钮**（以后改了文件要重新点一下更新）

---

## 第5步：自定义域名（可选）

如果你有自己的域名（如 `yuanshuwu.com`）：

1. Gitee Pages 页面 → 自定义域名 → 填入你的域名
2. 去域名服务商那里添加一条 CNAME 记录指向 `你的用户名.gitee.io`

没有域名就用 Gitee 给的免费网址，完全够用。

---

## 第6步：测试

1. 用手机浏览器打开网址
2. 注册一个账号
3. 浏览书籍 → 购买 → 扫码支付 → 提交
4. 电脑上打开同一网址 → 登录 `admin` / `admin123`
5. 点 ⚙️ → 看到订单 → 确认 → 手机端获得书籍 ✅

---

## 常见问题

**Q：上传后为什么打不开？**

A：需要到 服务 → Gitee Pages 点 **「启动」**（这一步很容易忘）

**Q：改了文件怎么更新？**

A：重新上传覆盖 → 再到 Gitee Pages 点 **「更新」**

**Q：手机打开显示不正常？**

A：清除浏览器缓存再试

**Q：其他人能访问吗？**

A：能，网址发给任何人都能打开
